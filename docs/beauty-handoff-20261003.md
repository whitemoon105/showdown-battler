## 已完成的实现

- 每次点击“新队伍”立即按当前精确规则生成完整合法队伍，包含配装，可直接保存和继续修改。候选来自同规则种子、统计及本地图鉴；工作线程完整校验后才填入，失败保留草稿。另有空白队伍入口。
- 编辑器、推荐、导入及规则切换共用完整配装和队伍校验。约束形态、道具、太晶、招式、EV、队伍组合及格式钩子，同时保留未完成草稿与逐项纠错。
- 单打选招、换人、强制换人自动提交；双打完成两只与必要目标后提交。选人阶段仍保留显式确认与撤销。镜像按钮在原生请求刷新时重新定位同一操作，避免点击刚刷新失联的旧按钮。
- 资源回退与图片尺寸使用相同解析链，修复变体拉伸；招式显示中文效果悬停。
- 音乐、音效分别调节，保存并迁移旧设置；本地训练家头像及名字 VS 开场，服务器结果驱动胜、负、平演出。
- 游戏模式的原生弹窗先隐藏再适配；账号、组队与规则入口进入自己的界面。规则悬停显示当前引擎继承的限制。
- 用户最后要求只可等比改变窗口大小：固定 16:10，默认 1440×900，最小 1152×720，关闭最大化与全屏入口。“关于与更新”说明这一限制。
- 修复显示缩放时 CSS 坐标和原生子窗口 DIP 换算；窄战场使用上下血条，操作内容允许滚动。
- 晨光的原生背景曾露出 640×360 矩形边缘，现将全场光幕与精灵镜头分离：光幕覆盖实际战场、保留原生透明度时间线；精灵与光点仍统一等比缩放。原生场景重建后重新绑定光幕，切回原网页时还原挂载。
